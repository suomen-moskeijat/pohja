# Issue tracker: GitHub (suomen-moskeijat/hallinta)

Tämän repon (pohja) tiketit ovat paneelin repossa. Kaikki tiketit ja spesifikaatiot ovat GitHub Issues -tiketteinä repossa **suomen-moskeijat/hallinta** – myös
sivupohjaa (suomen-moskeijat/pohja) koskevat. Tiketin otsikon alussa kerrotaan, kumpaa repoa se koskee:
`[pohja]`, `[hallinta]` tai `[pohja+hallinta]`.

suomen-moskeijat/hallinta on **yksityinen** repo: tiketit näkyvät vain organisaation jäsenille. Silti ei avaimia eikä
salaisuuksia tiketteihin, eikä moskeijoiden jäsenten tai kävijöiden henkilötietoja (pohja ja moskeijoiden repot ovat julkisia,
ja tiketeistä voidaan viitata niihin).

## Työkalut tässä ympäristössä

`gh`-komentoa ei voi käyttää kirjoittamiseen (vain hakuun). Käytä GitHubin MCP-työkaluja (lataa tarvittaessa ToolSearchilla):

- **Luo tiketti**: `mcp__github__issue_write` (method `create`, owner `suomen-moskeijat`, repo `hallinta`, title, body, labels)
- **Lue tiketti**: `mcp__github__issue_read` (method `get`, ja kommentit method `get_comments`)
- **Listaa tiketit**: `mcp__github__list_issues` (state, labels)
- **Kommentoi**: `mcp__github__add_issue_comment`
- **Labelit**: `mcp__github__issue_write` (method `update`, labels = koko uusi lista)
- **Sulje**: kommentoi ensin selitys, sitten `mcp__github__issue_write` method `update`, state `closed`, state_reason
- **Alitiketti**: `mcp__github__sub_issue_write` (method `add`); jos ei onnistu, rungon alkuun `Part of #<n>`
- **Esto**: rungon alkuun rivi `Blocked by: #<n>, #<n>`. Tiketti on aloitettavissa, kun kaikki estäjät on suljettu.
- **Haku**: `gh api -X GET search/issues -f q='repo:suomen-moskeijat/hallinta <hakusanat>'`

Jokaisen GitHubiin kirjoitettavan tiketin, kommentin tai rungon loppuun tulee rivi:

```

---
_Generated by [Claude Code](https://claude.ai/code)_
```

Älä koskaan kirjoita tikettejä repoon mattpocock/skills.

## Pull requests as a triage surface

**PRs as a request surface: no.**

## When a skill says "publish to the issue tracker"

Luo GitHub-tiketti repoon suomen-moskeijat/hallinta (yllä).

## When a skill says "fetch the relevant ticket"

Lue se kuten **Lue tiketti** yllä.

## Wayfinding operations

Used by `/wayfinder`. The **map** is a single issue labelled `wayfinder:map`; child tickets are sub-issues
(or listed in the map body with `Part of #<map>` in the child), labelled `wayfinder:<type>`
(`research`/`prototype`/`grilling`/`task`). Claim = kommentti "Claimed" ensimmäisenä kirjoituksena; resolve =
vastaus kommentiksi, sulje tiketti, lisää lyhyt viittaus kartan Decisions-so-far-kohtaan.

## Testaajille näkyvä osa

Tiketit ovat kehitystyötä varten. Testaajien kuittaukset tehdään edelleen pohja-repon `testi`-haaran
`testit.json`-tiedoston kautta (paneelin Testaus ja julkaisu -sivu): jokaisesta toteutetusta tiketistä kohta sinne.
